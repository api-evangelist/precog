# Precog

> Precog is an enterprise AI "context engine" that turns fragmented, context-stripped data from SaaS applications and databases into live semantic layers business users can query in natural language through AI assistants like Claude and ChatGPT. Its Intelligent Ingest builds no-code ETL pipelines into a data warehouse; its AI Assistants add source tracing and SQL visibility. Precog exposes a public HTTP REST API and an OAuth-secured Model Context Protocol (MCP) server.

## APIs
- [Precog Public HTTP API docs](https://studio.precog.cloud/docs/): Manage sources, destinations, pipelines, datasets, and semantic-model generation. Base URL https://api.precog.cloud, HTTP Bearer auth.
